# HeartGram: дорожная карта

Основа: [exteraless](https://github.com/exteraless/exteraless) (Telegram for Android 13.2.1).
Ниже то, что переносим из «мода», которым сейчас пользуемся (он собирается патчем готового APK),
и откуда берём остальное. Каждый этап проверяется в CI (`static` — компиляция, `apk` — полная сборка).

## Что уже есть в exteraless

- Режим призрака, сохранение удалённых и изменённых сообщений (классы `com.radolyn.ayugram.*`).
- Плагины exteraGram (Python/DEX/Xposed) с моделью разрешений.
- Настройки в духе exteraGram, плеер Material 3, пилюли, боковое меню, QR-вход.
- Локальный `BadgesController`: значок рисуется в профиле, в других местах нет.

## Секреты и данные, которых нет в репозитории

Репозиторий публичный, поэтому в него **не кладём**:

- адрес списка значков и ключ расшифровки закрытой части списка (`HG_LIST_URL`, `HG_SEAL_KEY`) —
  передаются при сборке из GitHub Secrets;
- `api_id` / `api_hash` Telegram, ключ подписи (`RELEASE_KEYSTORE`, `LOCAL_PROPERTIES`), Firebase-проект.

Без них клиент собирается и работает, но без значков HeartGram, с тестовым `api_id` и отладочной подписью.

## Принципы

- Только открытый код, лицензия GPL-3.0 и благодарность исходным проектам в README и в «О приложении».
