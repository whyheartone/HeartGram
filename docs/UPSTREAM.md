# Основа и обновления

HeartGram собран на основе [exteraless](https://github.com/exteraless/exteraless) (GPL-3.0).

- База: коммит `979e175a29f666768ebd0f134e27630fc9b65d4b` (ветка `main`, Telegram for Android 13.2.1).
- История коммитов exteraless в этот репозиторий не переносилась: все файлы импортированы одним коммитом.
- Чтобы подтянуть их новые изменения: добавить remote `upstream` (`https://github.com/exteraless/exteraless.git`) и
  сравнить `git diff 979e175a2..upstream/main`, затем применить нужное.

Спасибо exteraless, NagramX, exteraGram, AyuGram и DiveGram: без их открытого кода этого проекта не было бы.
